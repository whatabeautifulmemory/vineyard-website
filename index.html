ONE COMMAND

curl -fsSL https://vineyard.run/install.sh | bash

Picks the package for this machine — apt on Debian and Ubuntu, pacman on Arch and Omarchy, an AppImage in ~/.local/bin on any other distribution — and checks it against SHA256SUMS before installing.

OR DOWNLOAD A PACKAGE

X86_64ARM64 (AARCH64)
DEBUbuntu 22.04+, Debian 12+ Vineyard-linux-amd64.deb Vineyard-linux-arm64.deb
PACMANArch, Omarchy, other pacman distros Vineyard-linux-x86_64.pkg.tar.zst Vineyard-linux-aarch64.pkg.tar.zstincl. Apple Silicon via Asahi
APPIMAGEany distribution Vineyard-linux-x86_64.AppImage Vineyard-linux-aarch64.AppImage

The AppImage needs FUSE 2 (libfuse.so.2); the ARM64 one also needs libz.so — zlib1g-dev on Debian and Ubuntu, already there on Arch. Checksums: SHA256SUMS.

INSTALL A DOWNLOADED FILE
sudo apt install ./Vineyard-*.deb
sudo pacman -U ./Vineyard-*.pkg.tar.zst
chmod +x Vineyard-*.AppImage

Run in the folder the file was saved to. If that folder holds more than one Vineyard file, type the full name of the one you want in place of the Vineyard-* pattern. The AppImage needs no install: once it is executable, start it by its name, e.g. ./Vineyard-linux-x86_64.AppImage, from wherever you keep it.
